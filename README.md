# 提炼 · B 站视频 / 音频 / 封面提取

粘贴链接，选好画质，把想要的东西存到本地。支持一次处理多条。

本地运行，文件只落在你自己的硬盘上。

---

## 快速开始

双击 **`启动.bat`**，浏览器会自动打开界面。关掉那个黑窗口就是退出。

> 需要 Node.js 18 以上（[下载](https://nodejs.org/zh-cn)）。首次使用前在项目目录执行一次 `npm install`，会装上二维码组件和 ffmpeg（合计约 64MB 的依赖），后者用于 1080P 高清合并。

## 登录（解锁高画质）

**不登录 = 访客，最高 720P。** 这是 B 站服务端的限制。

**登录之后，只要本地有 ffmpeg**（项目已自带），1080P / 1080P60 / 4K 会直接出现在清晰度列表里。
B 站对 1080P 以上只给 DASH 分离流（画面和声音分成两个文件），程序会分别下完再用 ffmpeg 无损封装成一个 MP4。

登录步骤：

1. 点右上角「**游客**」按钮
2. 手机打开 B 站 App，点右上角「扫描」
3. 扫码后手机上点「确认登录」
4. 界面自动切到已登录状态，清晰度列表随即刷新出更高档位

登录凭证保存在本机 `config.json`，不会上传到任何地方，也不会发给第三方。

扫码一直不成功时，可以在 ⚙️ 设置里手动粘贴 `SESSDATA` 兜底。

## 关于音频

音频走 B 站的 DASH 独立音轨，落地为标准 **M4A（AAC）**，VLC、PotPlayer、手机自带播放器都能直接播，**不需要 ffmpeg 转码**。

三档音质访客即可获取：

| 档位 | 说明 |
| --- | --- |
| 64K | 流畅 |
| 132K | 标准 |
| 192K | 高品质 |

杜比全景声与 Hi-Res 无损需要大会员，登录后若账号有权限会自动出现在选项里。

## 文件保存在哪

默认在程序目录下的 `downloads/`。侧栏队列底部的「打开文件夹」直达（悬停可看当前路径），或在设置里改成别的位置。

命名规则：

```
视频标题 [清晰度].mp4
视频标题 - P2 分集名 [清晰度].mp4
视频标题 [192K 高品质].m4a
视频标题 - 封面.jpg
```

文件名里的清晰度是**实际下载到的档位**，不是请求的档位——避免标着 1080P 实际给 720P。

重名会自动加 `(1)`、`(2)`，并发下载也不会互相覆盖。

## 关于安全

这个程序能读写磁盘、能改设置、还存着你的登录态，所以按「最小可用权限」收紧了一层。
界面里只在设置底部给一行 **「本机保护 · 已开启」**，不罗列具体措施——
结论给到就够了，细节留在这一节和代码里。

### 访问控制

| 措施 | 挡的是什么 |
| --- | --- |
| **只监听 `127.0.0.1`** | 局域网内其他设备根本连不上，不是「有密码」而是「没有入口」 |
| **Host 头校验** | DNS 重绑定：恶意域名解析到 127.0.0.1 后，浏览器会把它当同源，Host 校验直接挡掉 |
| **Origin / Sec-Fetch-Site 校验** | CSRF：别的网站偷偷向你本机接口发写请求，一律 403 |
| **请求限流**（10 秒 240 次） | 脚本跑飞或死循环时不会把 B 站接口打爆 |

### 内容与数据

- **严格 CSP**：页面只能加载本文件的脚本与样式，图片只允许本站和 B 站图床。即使某条视频标题里塞了恶意脚本，也执行不了。
  主题预置脚本因此从内联改成了独立的 `/theme-init.js`。
- **响应头**：`X-Frame-Options: DENY`（防点击劫持）、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Permissions-Policy` 关掉定位/摄像头/麦克风。
- **凭证加密**：`config.json` 里只有 AES-256-GCM 密文（`cookieEnc`），密钥由「主机名 + 用户名」派生，
  **拷到别的电脑或别的用户下都解不开**。
- **文件权限**：每次启动都会重新收紧 `config.json`（Windows `icacls` 只留当前用户 / Unix `chmod 600`）。
- **封面代理白名单**：只代理 B 站图床，且**每一跳重定向都重新校验**，防止 302 跳到内网；
  响应必须真是图片，否则拒绝。
- **外部命令不用拼接**：打开文件夹、打开浏览器都改成「程序 + 参数数组」，路径里带引号或分号也不会变成命令。
- **路径与输入校验**：静态文件做真实路径穿越校验；保存位置必须是已存在的绝对路径；凭证长度设上限。

### 边界

这是**本机防护**：能挡随手翻看、误传配置文件、恶意网页借你浏览器调本地接口。
如果电脑本身已被控制（远程桌面、木马），任何本地加密都挡不住——那种情况需要系统级密钥管理。

## 常见问题

**Q：提示「触发风控」或下载变慢？**
B 站对高频请求有风控。隔几分钟再试，登录后明显改善。批量时程序已限制并发为 3。

**Q：某些视频解析失败？**
付费课程、充电专属、地区限制的内容拿不到地址，属正常。已删除的视频会直接提示「视频不存在」。

**Q：中断了怎么办？**
重新点下载即可。中断的临时文件（`.part`）会自动清理，不会留下半截文件。

**Q：批量下载多 P 视频会下全部集吗？**
不会，批量默认只下每个视频的第 1 集，列表里会标注「NP · 默认第 1 集」。要下其他集请单独解析。

**Q：音频能转 MP3 吗？**
当前不转。M4A 是 AAC 容器，体积更小、音质更好，主流播放器都支持。确有需要可用格式工厂之类工具转一次。

## 设计说明

界面走 **明亮二次元 / 贴纸感** 路线，刻意避开了常见的「深色 + 紫粉渐变」套路：

- **配色**：海雾白底 + **单一主色海蓝**（`#1976d2`），浪花青（`#22b8cf`）只做辅助（统计标签）。页面底色叠加了**背景插画 + 纵向遮罩 + 漫画网点**（14px 点阵），顶部露图、向下渐厚，正文始终清晰。
- **实体感**：按钮和卡片都带**底部硬阴影**，按下时真的会「陷进去」——模仿街机物理按键。卡片是 2px 粉边 + 偏移阴影的贴纸效果。
- **排版**：首屏标题收敛成单行（30–44px），900 字重 + 白描边 + 蓝色错位重影，「取」字配黄色荧光笔划痕。刻意不做「居中大标题 + 副标题 + 两按钮」的套路。
- **布局**：**桌面双栏**——左侧主操作（输入 / 结果），右侧固定栏（下载队列 / 小贴士）。宽屏下把 1500px 用满，不再是一条居中窄条；1120px 以下自动收成单栏，队列回到下方。
- **字体**：中文靠 800/900 字重与负字距撑气势，数字用圆体字族。没有引入网络字体——本工具离线可用，不能依赖 CDN。
- **动效**：一次统一入场（6 组错峰 70ms），`prefers-reduced-motion` 下全部关闭。
- **加载态**：封面与缩略图下载完成前显示 **shimmer 流光骨架**，加载失败则显示淡粉底，不留破图。
- **滚动进场**：结果卡与批量行由 `IntersectionObserver` 驱动，滚入视口时依次淡入（列表项错峰 55ms）。
- **半透明卡片**：所有卡片统一用 `--panel`（亮 84% / 暗 76%）+ `backdrop-filter`，插画能透过卡片看到；大卡模糊 18px、小卡 12–16px，弹窗用更实的 `--panel-strong` 保证表单可读。
- **基线对齐**：首屏标题横跨左右两列（`.hero { grid-column: 1 / -1 }`），主区与侧栏从同一条基线开始，右侧不再比左侧高出一截。
- **层次**：侧栏卡片背面透出插画，logo 悬停时轻弹一次。
- **背景水泡**：canvas 铺在内容之下，18–54 颗气泡缓慢上浮、带描边与高光，透明度 0.16–0.42。跟随主题换色，页面切到后台自动暂停，设置里可关闭，系统开了「减少动态效果」则不启动。
- **进度条**：填充端带一个发光**墨头**与流动光泽，像笔尖推着墨走；填满时轻微回弹，收成绿色实心。
- **深色主题**：右上角太阳 / 月亮切换，跟随系统偏好，手动选择记在 `localStorage`。深色版是「深海」——深海蓝底 `#061426`、提亮的海蓝、网点降到 9%，配合插画比亮色版更有氛围。切换时全站做 220ms 过渡，避免硬闪。

**无障碍修正**：主色按钮最先配白字，对比度只有 2.9:1（低于 4.5:1 标准）。现改为深海蓝底（`#1976d2` → `#0d47a1`）配白字，对比度 4.6–6.3:1，勾选框、分集选中态、序号徽章一并修正。

**布局细节**：单条解析时，分集选择器放在**封面下方的空位**，右侧只保留标题、UP、统计与操作按钮——中等宽度下右侧不再被分集挤成一团。窄屏单列时顺序回到「封面 → 信息 → 分集」。

- **清晰度说明**：结果区顶部一句话，按「是否登录 / 是否有 ffmpeg」四种组合给不同文案，不用猜为什么没有 1080P。
- **数据条**：播放 / 点赞 / 投币 / 收藏做成等分四格，各配一枚线性图标与独立色相（蓝 / 青 / 琥珀 / 蓝紫），竖线分隔；次要数据压成一行小字，不跟主数据抢注意力。
- **封面柔光**：详情卡顶部用封面图模糊铺一层 26–32% 的柔光，卡片不再是死白（深色下 26%），内容区始终压在上面。
- **首屏引导**：未解析时显示三步卡片（粘贴 → 挑分集 → 下载），解析后自动让位给结果。
- **侧栏小贴士**：快捷键与几个容易踩的点。保存位置只在设置里维护，侧栏不再单开一张卡占地方。
- **免责声明**：页面最底部常驻，说明仅供学习、版权归原作者、24 小时内删除。

记忆点：**插画背景 + 会「按下陷进去」的海蓝按钮 + 漫画式错位标题**。

## 技术说明

**为什么必须有一个本地服务？**

B 站视频流有防盗链，请求必须带 `Referer: https://www.bilibili.com`，否则返回 403。浏览器的 `fetch` 与 `<video>` 都**不允许**自定义 `Referer`，所以纯前端网页做不到。本工具用 Node 起了一个只监听 `127.0.0.1` 的服务做代理。

**720P 与 1080P 为什么走两条路？**

B 站有两条通道：

- `fnval=1`（DURL）返回**音视频已合并**的单文件 MP4，落地即播，但天花板是 720P。
- `fnval=4048`（DASH）返回**画面与声音分开**的流，登录后能拿到 1080P / 1080P60 / 4K，但必须自己合并。

所以程序按清晰度自动分流：≤720P 走 DURL（快、省事），>720P 走 DASH + ffmpeg `-c copy` 无损封装（不重新编码，几十秒完成）。ffmpeg 用的是随项目安装的静态二进制，不需要你另外配置环境变量。

**清晰度为什么显示得这么准？**

DURL 返回的 `accept_quality` 是**真实可用**列表；DASH 返回的是「理论上限」——访客会看到 1080P 选项却下不动。所以画质探测一律走 DURL，给你列的每一档都真能下到。

**音频为什么能直接用？**

B 站 DASH 音频轨是标准 fMP4（`ftyp` + `moov` 在文件头部），本身就是合法的 M4A 容器，改后缀即可播放，无需转封装。
